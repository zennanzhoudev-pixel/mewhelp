# Ch01 纯对话客服 · 开发留痕

## 目标
跑通「跟大模型对话」:SSE 流式、Prompt 工程化、结构化售后提取、token 预算裁剪。不做工具调用、不做 Agent 循环。

## 关键决策
- 上游接入:应用直连,`.env` 里分 `CHAT_* / EMBED_* / RERANK_*` 三组,代码统一说 OpenAI 协议。
- 会话管理:服务端 `session_id` 存内存(ch02 起落 MySQL),调用前 `trim_messages` 按 token 预算裁剪。
- 提取形态:独立 `POST /api/extract`,`with_structured_output` 绑定 `AfterSalesTicket`。
- 依赖管理:uv(定死)。

## 交付物
- `app/config.py`、`app/core/{llm,prompts,memory}.py`、`app/api/{chat,extract}.py`、`app/main.py`
- `tests/test_{config,schemas,memory,prompts,llm,chat_api,extract_api}.py`
- `scripts/{dev.sh,eval_extract.py,demo_chat.sh}`、`tests/data/extract_samples.json`

## 测试结论
- 确定性代码(配置/schema/记忆裁剪/模板/模型工厂/SSE 组帧/提取接口)全部 TDD,单测用 FakeModel 与依赖注入,不打真实模型。
- 标注样例(`extract_samples.json`)与两轮对话 demo 需真实上游 key,由用户填 `.env` 后跑 `make eval` 与 `./scripts/demo_chat.sh`。

## 需用户独立完成
- 在 `.env` 填 `CHAT_BASE_URL / CHAT_MODEL / CHAT_API_KEY` 后跑 Task 5 上游冒烟与 Task 8 真实验收。
