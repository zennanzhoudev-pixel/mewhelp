# Ch08 即插即用工具系统 · 开发留痕

## 目标
统一工具注册中心 + 执行引擎 + MCP 接入 + 建工单确认流:内置工具与 MCP 工具登记同一张表,新工具注册即用不改核心代码、不重启。

## 关键决策
- 注册中心统一登记「名字 + 用途描述 + JSON Schema」;内置启动时登记,MCP 连上 Server 动态发现、现问现拿。
- 执行引擎统一管校验/超时/重试/错误分诊/结果格式化;重试只给暂时性故障,写操作默认不自动重试。
- 权限我们侧独裁:写清单按名字定,未登记(含所有 MCP)工具一律只读放行;外部 Server 的用途声明不可信。
- create_ticket 走确认流:Agent 核对信息 → 引擎不直接执行 → interrupt 推工单预览卡片 → 确认才落 tickets、取消按「权限拒绝」落审计。
- 物流查询由物流 MCP Server 接管,内置 query_logistics 下线,不留重名工具。
- 审计落 tool_audit_logs,不挂外键,写审计失败不许拦工具执行。

## 交付物
- `app/tools/{registry,engine,mcp_client,business}.py`、`app/tools/builtin/*`、`mcp_servers/{logistics_server,aftersales_server}.py`
- `sql/ch08-ddl.sql`、`scripts/eval_ch08.py`、前端工单预览卡片
- `tests/tools/test_{engine,mcp_client,mcp_servers,registry}.py`、`tests/graph/test_ch08_confirm_ticket.py`

## 验收
`make mcp-up` 起两台 MCP Server 后 `make eval-ch08`;浏览器验证工单确认/取消、审计、超时重试。

## 需用户独立完成
- 本地起 MCP Server 与全服务后跑真实 MCP 动态发现/确认流验收。
