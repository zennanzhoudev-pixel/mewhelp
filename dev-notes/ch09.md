# Ch09 可观测性与数据飞轮 · 开发留痕

## 目标
接 Langfuse 全链路可观测 + Cost Control + 三入口问题池 + 标准化查重待审队列 + 人工审核写回 + 评估趋势。

## 关键决策
- Langfuse 自部署(Langfuse 4,open-source),三环境变量齐全才挂回调,缺省系统照常跑;编译时挂一次,图节点零侵入。
- 置信度闸正式版:检索+精排结果算 evidence_confidence(精排 Top1 分、有效证据数、Top1/Top2 分差),阈值用 ch04 评估集校准(实测 YoudenJ 最优点 0.26),不拍脑袋。
- 数据飞轮三入口:检索证据低 / 生成自评不足 / 用户 👎 反馈,都落 low_confidence_questions 并带回当轮召回片段快照。
- 标准化查重:口语改标准问法 + 示例答案,与待审队列按语义去重(同义累加 occurrence_count 不新建行),归并落点记回 matched_review_id。
- 评估流水线复用 ch04 评估集,每轮分数落 eval_runs 连趋势。

## 交付物
- `app/core/{observability,confidence,flywheel}.py`、`app/api/{observability,review,feedback,topics}.py`
- `sql/ch09-ddl.sql`、`docker-compose.langfuse.yml`、`scripts/{calibrate_confidence,flywheel_pipeline,eval_flywheel,cost_by_intent,validate_flywheel_samples}.py`
- 前端待审队列 / 观测成本 / 主题分布页

## 验收
`make langfuse-up` 起观测栈、`make flywheel` 跑飞轮批处理、`make eval-flywheel`、`make cost-report`;Langfuse 点开任意请求看完整链路。

## 需用户独立完成
- 起 Langfuse 自部署栈 + 真实上游后跑完整飞轮与成本账;阈值已在评估集上校准回填,换知识库后建议重跑 `make calibrate-confidence`。
