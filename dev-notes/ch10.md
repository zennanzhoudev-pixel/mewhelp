# Ch10 模型微调:多标签主题分类器 · 开发留痕

## 目标
RoBERTa-wwm-ext 全参微调一个多标签主题分类器(17 类),挂在旁路批量给低置信问题归类,结果写 topic_classifications 喂飞轮后台主题分布页。

## 关键决策
- 17 类权威类目表全系统一份,退换货/物流/尺码/发票领头,近邻类目靠边界说明划开。
- 数据处理四步:清洗 → 归并术语表 → 80/10/10 分层抽样 → 数据增强(只扩训练集)。
- 标注走大模型照术语表预标 + 人工抽审;多标签,字面提到几个打几个。
- RoBERTa-wwm-ext 全参微调(不用 LoRA,那个量级才用 PEFT),验证集盯分数 + 正则 + 早停。
- 部署导 ONNX 轻运行时,旁路批量归类;实时对话主链路不调它。

## 交付物
- `scripts/ch10/{build_corpus,build_dataset,train,evaluate,export_onnx,serve,classify_pool,prelabel,scan_threshold_replay,validate_golden}.py`
- `sql/ch10-ddl.sql`、`app/core/taxonomy.py`、`app/api/topics.py`、前端主题分布页
- `tests/test_ch10_{corpus_lib,inference_lib}.py`

## 验收
`make ch10-golden` → `ch10-corpus` → `ch10-dataset` → `ch10-train` → `ch10-eval` → `ch10-export` → `classifier-up` → `classify-pool`;测试集各类目 F1 + 混淆矩阵报告。

## 需用户独立完成
- ch10 训练/导出重依赖(torch/transformers 等)走 ml 组(`uv run --group ml ...`),需 GPU 或 MPS;数据与训练、阈值扫描、旁路归类由本地执行。
